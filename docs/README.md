# Documentation Index

This `docs/` folder contains the project documentation for **Multi-Tenant SaaS Backend Platform**.

## Files
- `01-overview.md` — business goal, scope, and core features
- `02-architecture.md` — application structure and request flow
- `03-setup-and-run.md` — environment variables, runtime, and startup guidance
- `04-api-reference.md` — endpoint reference and example request flow
- `05-data-model-and-security.md` — entities, JWT handling, and storage behavior
- `06-troubleshooting.md` — common issues and fixes

## Current implementation status
This repository is a **starter backend implementation** for a multi-tenant SaaS system. It includes Echo-based API routes, PostgreSQL persistence through GORM, JWT authentication, and optional S3/R2-compatible manifest upload.
